# Як зібрати контролер: покроковий посібник

Посібник веде від купівлі деталей до працюючого пристрою з веб-меню. Якщо спершу хочеться просто подивитись на інтерфейс, почніть з [емулятора](#крок-0-подивитись-без-заліза): він запускає справжню прошивку на комп'ютері.

---

## Крок 0. Подивитись без заліза

```bash
git clone https://github.com/Volod3/esp32-home-controller.git
cd esp32-home-controller
pip install platformio            # якщо ще нема
pio run                           # один раз: скачає бібліотеку U8g2
python3 emulator/emulator_web.py  # відкриється http://127.0.0.1:8765
```

Керування мишею над екраном: коліщатко — крутилка, ліва кнопка — OK, права — BACK, середня — CONF. Праворуч є повзунки «датчиків», ними можна погратися з освітленістю й напругою акумуляторів.

---

## Крок 1. Деталі

| Що | Скільки | Примітка |
|---|---|---|

| Модуль реле 5 В або реле + NPN-транзистор (2N2222/BC547) + діод 1N4007 + резистор 1 кОм | 3 | «Вмикається HIGH» |
| Енкодер з кнопкою (KY-040) | 1 | |

| ІЧ-приймач VS1838B / TSOP | 1 | необов'язково |
| Адресна стрічка WS2812B | 1 | 8 світлодіодів за замовчуванням |
| Резистори для дільника «світло в домі» | 2 | див. крок 2 |
| Блок живлення 5 В, дроти, макетка або плата | | |

## Крок 2. Підключення

### ESP32

| Пін ESP32 | Куди |
|---|---|
| 3V3, GND | живлення OLED і INA3221 |
| 21 (SDA), 22 (SCL) | SDA / SCL **і** OLED, **і** INA3221 (одна шина I2C) |
| 25 / 26 / 27 | вхід реле 1 (RGB) / 2 (LED) / 3 (гірлянда) |
| 34 | середня точка дільника фоторезистора |
| 35 | дільник «світло в домі» |
| 16 (RX2) | TX Pro Micro (пін 1) — **через дільник, якщо Pro Micro 5-вольтова** |
| 17 (TX2) | RX Pro Micro (пін 0) |
| GND | спільна «земля» з Pro Micro, реле, стрічкою |

**Фоторезистор.** Фоторезистор між 3V3 і піном 34, резистор 10 кОм між піном 34 і GND. Що світліше, то вища напруга. Сам датчик не має «дивитись» на лампу, яку вмикає.

**«Світло в домі».** Дільник від 5-вольтового блоку живлення, який працює від мережі (не від акумулятора). Наприклад, 10 кОм зверху і 5,6 кОм знизу дають ~1,8 В. Поріг «світло є» — 1 В. Напруга на піні 35 не має перевищувати 3,3 В.

**Реле.** Модуль «HIGH = увімкнено» підключається напряму. Голе реле — через NPN-транзистор: база через 1 кОм до піна, емітер на GND, реле між +5 В і колектором, діод паралельно котушці (катодом до +5 В).

**INA3221.** Канал 1 — лінія 5 V, канал 2 — основний акумулятор, канал 3 — резервний. Якщо у вас інакше, змініть `BAT1_INA_CH`, `BAT2_INA_CH` і `LINE_INA_CH` на початку `src/main.cpp`.

### Pro Micro

| Пін Pro Micro | Куди |
|---|---|
| 0 (RX) / 1 (TX) | 17 / 16 ESP32 |
| 3 / 7 | енкодер A / B (другий вивід енкодера — GND) |
| 4 | кнопка енкодера (OK) → GND |
| 8 | кнопка BACK → GND |
| 2 | кнопка CONF → GND |
| 9 | вихід ІЧ-приймача |
| 10 | DIN стрічки WS2812B (бажано через резистор 330 Ом) |

Кнопки підключаються між піном і GND, підтяжка вже ввімкнена в прошивці. Стрічку живіть від 5 В блоку, а не від Pro Micro.

---

## Крок 3. Важливо про рівні напруги

ESP32 працює на 3,3 В, і його піни **не витримують 5 В**. Якщо Pro Micro 5-вольтова (16 МГц), її вихід TX (пін 1) підключайте до піна 16 ESP32 через дільник 1 кОм / 2 кОм. Інакше можна з часом спалити пін. З Pro Micro 3,3 В / 8 МГц дільник не потрібен. У зворотний бік (TX ESP32 → RX Pro Micro) 3,3 В зазвичай читаються нормально.

## Крок 4. Програми

1. Поставте [VS Code](https://code.visualstudio.com/) і розширення **PlatformIO IDE**. Або лише CLI: `pip install platformio`.
2. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/Volod3/esp32-home-controller.git
   cd esp32-home-controller
   ```

## Крок 5. Особисті налаштування

```bash
cp include/secrets.example.h include/secrets.h
cp secrets.example.ini secrets.ini
```

У `include/secrets.h`:

- `WIFI_SSID` / `WIFI_PASS` — ваш Wi-Fi. Можна лишити порожніми й вибрати мережу потім у веб-меню.
- `OTA_PASS` — пароль для прошивки по повітрю. Такий самий пароль впишіть у `secrets.ini` (`--auth=...`).
- `AP_SSID` / `AP_PASS` — власна точка доступу контролера (пароль мінімум 8 символів).
- `WEATHER_LAT` / `WEATHER_LON` / `WEATHER_PLACE` — ваші координати для погоди.

Обидва файли не потрапляють у git, тож паролі лишаються у вас.

---

## Крок 6. Прошивка ESP32 (вперше — по кабелю)

Підключіть ESP32 по USB і виконайте:

```bash
pio run -e usb -t upload
pio device monitor        # журнал: побачите IP після підключення до Wi-Fi
```

Якщо завантаження не стартує, затисніть кнопку **BOOT** на платі, поки не почнеться запис.

---

## Крок 7. Прошивка Pro Micro

```bash
cd promicro
pio run -t upload
cd ..
```

Після старту стрічка коротко блимне червоним, зеленим і синім: Pro Micro працює.

---

## Крок 8. Перший запуск

1. На екрані з'явиться «Запуск...», потім головний екран.
2. **Якщо Wi-Fi не вказано** (або мережа недоступна 2 хв), контролер підніме точку доступу `ESP32-Control`. Підключіться до неї телефоном і відкрийте **http://192.168.4.1**. Далі «Налаштування» → «Мережа Wi-Fi» → «Знайти мережі», виберіть свою і введіть пароль.
3. Коли плата в домашній мережі, веб-меню відкривається на **http://esp32-test.local** або за IP з журналу.
4. Погода й точний час з'являться за кілька секунд після підключення до інтернету.

---

## Крок 9. Налаштування під себе

- **Пороги реле.** Екран «Реле» → OK → виберіть реле → OK, далі крутилкою поставте поріг, BACK — зберегти. Те саме можна робити повзунками у веб-меню, вкладка «Реле».
- **Слова освітленості** (Темно / Сутінки / Світло / Яскраво). У меню «Settings» або у веб-меню є ручні межі у вольтах: поставте їх так, як ваш фоторезистор показує вдень і вночі.
- **Нічне вимкнення, «За сонцем», затримка, сон екрана.** Меню «Settings».
- **Стрічка й яскравість екрана.** Меню «Light».
- **ІЧ-пульт.** Натисніть кнопку пульта й гляньте в «Info» → «Остання подія» (`IR,NEC,0x..,0x..`). Другий параметр — адреса пульта, впишіть її в `IR_ADDR` у `src/main.cpp`, щоб чужі пульти не спрацьовували.

---

## Крок 10. Оновлення по повітрю

Після першої прошивки кабель більше не потрібен:

```bash
pio run -t upload          # env:ota, адреса esp32-test.local
```

Якщо `esp32-test.local` не знаходиться, впишіть IP плати в `upload_port` у `platformio.ini`.

## Якщо щось не так

| Симптом | Що перевірити |
|---|---|
| Екран чорний | Живлення 3,3 В, SDA/SCL не переплутані, екран саме SH1106 (адреса 0x3C) |
| Сміття на екрані або екран «перевертається» | Довгі дроти I2C, нема підтяжок 4,7 кОм. Можна знизити `OLED_I2C_HZ` до `400000` |
| АКБ показують «--» | INA3221 на шині I2C (адреса 0x40), спільна GND |
| Переплутані акумулятори | `BAT1_INA_CH` / `BAT2_INA_CH` у `src/main.cpp` |
| Енкодер крутить навпаки | Поміняйте місцями дроти A і B (піни 3 і 7) |
| Кнопки не реагують | Info → «Pro Micro»: має бути «зв'язок є». Інакше перевірте RX/TX (навхрест) і GND |
| Реле не клацає | Модуль має бути «HIGH = увімкнено». Для «LOW = увімкнено» поставте `RELAY_ACTIVE_LOW 1` |
| Не прошивається по OTA | Плата й комп'ютер в одній мережі, пароль у `secrets.ini` збігається з `OTA_PASS` |
| «Фоторезистор не підключено» | На піні 34 менше 0,1 В: обрив дільника |
